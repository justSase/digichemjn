# Nachziehen — was die anderen Notebooks später von der Vorlage/Complex bekommen

*Seit 27.10.2026 im Repository (`docs/`); die Hauptwerkstatt trägt je Version eine Zeile ein — die Änderung reist mit dem MERGE-Diff.*

*Angelegt 2026-09-27 21:3x UTC (Dirigent), auf Anweisung des Nutzers:*
**„Erst nur Complex, wirklich nur das eine Notebook. Verweise anlegen, damit
beim Nachziehen nichts vergessen wird."**

## Die Regel bis zum Nachziehen

- **Gebaut, getestet, gemessen und ausgeliefert wird nur
  `Complex_Numbers_Step_by_Step`.** Start, Sets, ML und Modeling werden nicht
  gebaut und nicht ausgeliefert. Sie bleiben im Ordner `Notebooks\` auf dem
  Stand, den sie haben (zuletzt v1.9 aus 27e). Aus dem **Ordner** `Notebooks\`
  werden sie nicht gelöscht.
- Suiten nur für Complex: `test_nb` `test_checks` `test_gating` `test_answers`
  `test_fixed` `test_js`. **`test_links` ruht**, weil es alle fünf braucht. Es
  läuft wieder beim Nachziehen.
- Die Werkstätten ändern das gemeinsame Toolkit weiter. Dabei darf ein anderes
  Notebook kaputtgehen, ohne dass es jemand merkt. **Deshalb trägt jede
  Werkstatt hier ein, was sie am Toolkit geändert hat**, wenn die Änderung die
  anderen vier betrifft. Eine Zeile im Abschnitt „Toolkit-Änderungen seit
  27d“ genügt.
- **Inhalt arbeitet nur an Complex.** Angefangene Arbeit an den anderen vier
  bleibt als Patch liegen und steht unten.
- **Wann nachgezogen wird, sagt der Nutzer** („Complex ist final“). Vorher
  keine Nachtschicht P1 „Nachziehen“.

## Beim Nachziehen: in dieser Reihenfolge prüfen

1. **Toolkit-Stand**: alle vier mit dem aktuellen Bündel bauen, alle sieben
   Suiten inklusive `test_links`. Jede Zeile unter „Toolkit-Änderungen“ gezielt
   nachmessen.
2. **Inhalt-Patches** einspielen (unten), rebasen, wo nötig.
3. **Panel für ML und Modeling anhängen** (`progress.py` fehlt dort im Build).
   Dann fällt die Übergangszeile `_run_finalizers(); _progress_resume()` weg.
4. **Alles, was Complex tags bekommen hat**, je Notebook nachbauen (Liste
   „Complex-Stand“ unten) und im echten Lab messen wie bei Complex.
5. Eine Nacht = ein Notebook, Reihenfolge Sets · Start · Modeling · ML
   (`WARTESCHLANGE.md` P1).
